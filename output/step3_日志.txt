========================================================================
  3.4  刻度化
========================================================================
PDO = 20，基准分 600 @ odds 50:1
B = PDO / ln2 = 28.8539
A = 基准分 + B x ln(基准odds) = 487.1229
score = A - B x ln( p / (1-p) )，每箱得分 = -B x 系数 x WOE
